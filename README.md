# Delivery System (Java)

Projeto simples desenvolvido em Java para praticar conceitos de Programação Orientada a Objetos.

## Objetivo

Simular um sistema de cálculo de entregas, onde o usuário escolhe o tipo de entrega e informa a distância para obter o valor final.

---

## Funcionalidades

- Seleção do tipo de entrega:
  - Car
  - Bike
  - Express
- Cálculo automático do valor da entrega
- Entrada de dados via console
- Exibição formatada dos resultados

---

## Conceitos aplicados

- Interface (`DeliveryService`)
- Polimorfismo
- Encapsulamento
- Estruturas condicionais (if/else)
- Listas (`List`)
- Entrada de dados com `Scanner`

---

## Regras de cálculo

- Bike: $1.00 por km  
- Car: $2.00 por km  
- Express: $3.00 por km + $10.00 fixo  

---

## Exemplo de execução
How many deliveries? 3

Delivery #1
Delivery type (a = Car, b = Bike, c = Express): a
Distance: 6
Car - $6.00

Delivery #2
Delivery type (a = Car, b = Bike, c = Express): c
Distance: 15
Express - $15.00

Delivery #3
Delivery type (a = Car, b = Bike, c = Express): b
Distance: 9
Bike - $9.00
